Reports a step that no step definition matches.

Cucumber reports such a step as undefined and does not run the scenario. The quick fix writes the missing method, deriving {int}, {string} and {float} parameters from the step text.

The fix adds the method to the file that already holds the most step definitions. With no step definitions anywhere in the module it is not offered, rather than guessing at a package.

This replaces the Gherkin plugin's own Undefined step inspection, which is suppressed: that one asks every step definition in the module about every step, on every highlighting pass.
